# Echo Void

Echo Void is a custom WordPress website and theme project focused on urban exploration (urbex), abandoned places, forgotten architecture, Soviet-era buildings, industrial ruins, photography and exploration.

The project was developed as a vocational school PT/VTT project in Information and Communications Technology / Software Development – Web Development.

## Project Overview

Echo Void combines an urbex-themed WordPress website with content, articles, galleries and an e-commerce section.

The long-term concept is to develop Echo Void into an international urbex platform where users can discover abandoned places, explore destinations, access curated maps and participate in an urban exploration community.

## Design

The visual identity is based around:

- Dark backgrounds
- Industrial and abandoned environments
- Brutalist-inspired layouts
- High contrast
- Neon green accent color
- Red warning/danger accents
- Monospace typography
- Black Ops One display typography

The design aims to create an underground, raw and industrial atmosphere while keeping the website usable and readable.

## Project Structure

The theme contains the main WordPress theme files and assets required to run Echo Void.

Important theme components include:

- `front-page.php` — homepage
- `header.php` — site header and navigation
- `footer.php` — site footer
- `style.css` / main CSS — visual styling
- `main.js` — navigation and frontend functionality
- WordPress template files
- Theme assets and images

## WooCommerce

WooCommerce is used for the commercial side of Echo Void.

The website supports products such as:

- Digital urbex map packs
- Urbex experiences
- Guided exploration tours

The homepage also contains featured WooCommerce products that link directly to their individual product pages.
